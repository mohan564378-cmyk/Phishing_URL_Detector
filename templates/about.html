🔐 Phishing URL Detection System

A web-based cybersecurity project that analyzes URLs and provides an automated risk assessment.

📖 1. Introduction

Phishing is a cybersecurity threat in which deceptive websites or URLs may be used to trick users into providing sensitive information.

This project provides an educational system for analyzing URL characteristics and identifying potentially suspicious URLs.

🎯 2. Project Objective

The main objective of this project is to develop a simple web application that can analyze URLs and classify them according to their estimated risk level.

The system combines rule-based analysis with a machine learning model.

⚙️ 6. System Working

Step 1: User enters a URL.

Step 2: The system validates the URL.

Step 3: URL characteristics are analyzed.

Step 4: The machine learning model analyzes the URL.

Step 5: Rule-based and ML results are combined.

Step 6: A final risk score is calculated.

Step 7: The scan result is stored in MySQL.

Step 8: The result is displayed to the user.

🤖 7. Machine Learning

The project uses a text-based machine learning approach to analyze URL patterns.

TF-IDF character features are used to convert URLs into numerical features.

A Logistic Regression model is used for classification.

🗄️ 8. Database

Database Name: phishing_detector

Table Name: scan_history

The database stores the URL, risk score, result and scan time.

🚦 9. Result Categories

🟢 Likely Safe — Low estimated risk.

🟠 Suspicious — Requires additional caution.

🔴 Likely Phishing — Higher estimated risk based on the current analysis.

⚠️ 11. Project Limitations

This system is designed for educational and demonstration purposes.

The current machine learning dataset is small and synthetic, so the model should not be considered a production security solution.

A larger, representative dataset and additional security validation would be required for real-world deployment.
